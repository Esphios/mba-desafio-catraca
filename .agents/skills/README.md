# Skills locais

Cada skill contém objetivo, entradas, procedimento, gate e entregável. A ferramenta pode carregar o arquivo como skill nativa ou contexto explícito; não assume plugin externo. O coordenador seleciona skills da tarefa.

| Skill | Aplicação |
| --- | --- |
| [prd-design](prd-design/SKILL.md) | Revisar produto e rastreabilidade antes de implementação |
| [architecture-review](architecture-review/SKILL.md) | Revisar HLD/FDD/ADR e diagramas |
| [schema-review](schema-review/SKILL.md) | Projetar e validar modelo relacional |
| [harness-engineering](harness-engineering/SKILL.md) | Construir ambiente e gates reproduzíveis |
| [feature-implementation](feature-implementation/SKILL.md) | Implementar uma feature com contrato |
| [secure-boundaries](secure-boundaries/SKILL.md) | Implementar autenticação, autorização e input safety |
| [transaction-safety](transaction-safety/SKILL.md) | Implementar invariantes e locks reais |
| [payment-simulation](payment-simulation/SKILL.md) | Implementar gateway durável e deadlines |
| [partner-api-contract](partner-api-contract/SKILL.md) | Preservar contrato de parceiro |
| [browser-validation](browser-validation/SKILL.md) | Validar comportamento UI real |
| [concurrency-validation](concurrency-validation/SKILL.md) | Provar corridas e testar sensibilidade |
| [independent-evaluation](independent-evaluation/SKILL.md) | Julgar contrato sem viés de implementação |
| [wave-orchestration](wave-orchestration/SKILL.md) | Planejar e integrar branches paralelas |
| [release-validation](release-validation/SKILL.md) | Exercer produto integrado e entrega |
