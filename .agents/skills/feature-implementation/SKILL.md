# feature-implementation

## When to use
Implementar uma feature com contrato. Leia AGENTS.md e tarefas da feature primeiro.

## Inputs
feature FDD/plan/contract, SHA, skills técnicas. Confirme SHA, fase e ownership.

## Procedure
Ler interfaces providers; executar passos em ordem, testes positivos/negativos; ownership restrito; commit útil por etapa; declarar desvios e bloqueios; entregar handoff.

## Validation
G1–G4 conforme feature; testes nomeados, não autoavaliar.

## Output and guardrails
Candidate SHA e comandos, sem relatório independente. Se faltar pré-requisito, registre bloqueio, não fabrique evidência. Não substituir regra normativa por conveniência.
